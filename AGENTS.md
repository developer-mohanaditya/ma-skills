# Instructions for ma-skills

## Purpose

This repository is a personal library of reusable agent skills for the owner's workflows. Skills may cover project setup, development, personal writing, or other tasks. Keep each skill focused on its own purpose; do not assume every skill is for coding projects.

## Working in this repository

- Maintain each skill in `skills/<skill-name>/` with a `SKILL.md` and the supporting files it needs. Preserve the skill's intent and existing behavior when updating it.
- Use the Agent Skills format for portable instructions. Keep tool-specific requirements explicit and record confirmed compatibility or limitations in `docs/compatibility.md` when relevant.
- Add or update the catalog in `README.md` when a skill is added, renamed, or materially changed. Keep installation and usage guidance accurate.
- Treat external services, credentials, private content, and publishing actions according to the user's instructions and the applicable skill. Do not include secrets or private diary entries in this public repository.
- Do not assume that installing a skill makes its instructions mandatory in every tool or environment. Document any supported project instruction setup separately.
- Verify changed skills and supporting files with checks appropriate to the change. Preserve unrelated skills and project instructions.

## Git and publishing

Before creating a commit or performing a GitHub publishing operation, read `project-identity-policy.md` and follow its account selection, authorization, attribution, and verification requirements.
